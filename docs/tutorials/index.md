# Tutorials overview

The Continuous Compliance Framework (CCF) tutorials are hands-on walks through the tasks you do in CCF: collecting evidence, describing your systems and the controls they meet, managing risks and running workflows. They are written for compliance and GRC users working in the UI, and for operators setting CCF up and extending it.

Each tutorial starts from a clean state and ends with a result you can inspect in the UI. Work through them in order the first time; after that, jump straight to the one that matches your task.

## Tutorial groups

Tutorials are grouped by the area of CCF they cover:

- **Evidence and Catalog:** collect your first evidence and build the catalogs, profiles and filters that turn evidence into compliance answers. See [Concepts](../concepts.md#catalog) for how these pieces fit together.
- **System:** register a system, select the profiles it attests to, record its control implementation and link evidence to it.
- **Risk:** create risks, plan and track mitigations, manage the risk lifecycle and read the risk dashboard.
- **Workflows:** create and share workflow definitions, execute instances and drive them to a done or failed state.
- **Plugins:** install CCF locally, add a plugin to your CCF Agent and see the evidence it captures.

If you are new to CCF, start with the [Introduction](../introduction/index.md) and the [glossary](../glossary.md), which define the terms these tutorials use.
